# Public repository, private design notes

The submission is single-blind, so anonymization is unnecessary — and the preregistration's credibility rests on a public commit history that predates data collection, so the repository is public from the start. `.reference/` (internal design notes: funding details, advisor decision records, pre-decision drafts) is gitignored and never published. Settled decisions surface publicly as ADRs here, and the preregistration tagged at W8 must be fully self-contained: it restates research questions, cells, exclusion rules, and the statistical plan without citing any private document. Zenodo DOI and the ACM Artifacts Available badge are W8 checklist items.
